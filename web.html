Practical 1: Install and Configure a Local Web Server

Aim: Install and configure a local web server environment using XAMPP/WAMP/LAMP and test it with basic HTML and PHP pages.

1. What is a Local Web Server?

A local web server allows us to run and test websites on our own computer without uploading them to the Internet. In XAMPP, Apache acts as the web server and PHP is processed by the server.

2. XAMPP Folder Structure

Folder/FilePurpose
xampp/htdocs/Default folder where website files are stored.
ApacheHandles HTTP requests and serves web pages.
PHPExecutes server-side PHP code.
phpMyAdminWeb interface for managing MySQL/MariaDB databases.

3. Steps

  1. Install XAMPP.
  2. Open XAMPP Control Panel.
  3. Start Apache.
  4. Create a folder such as web_lab inside htdocs.
  5. Put your HTML/PHP files inside that folder.
  6. Open http://localhost/web_lab/ in a browser.
File 1 — index.html
<!DOCTYPE html>
<html lang="en">
<head>
    <title>XAMPP HTML Test</title>
</head>
<body>
    <h1>Hello from XAMPP</h1>
    <p>Apache is serving this HTML page successfully.</p>
</body>
</html>

Explanation: Save this as index.html inside htdocs/web_lab/. Visit http://localhost/web_lab/.

File 2 — test.php
<!DOCTYPE html>
<html lang="en">
<head>
    <title>PHP Test</title>
</head>
<body>

<h1>PHP Test</h1>

<?php
echo "<p>PHP is working successfully.</p>";
echo "<p>Welcome to XAMPP!</p>";
?>

</body>
</html>

Explanation: PHP code is placed between <?php and ?>. PHP must be processed through a server such as Apache; opening the file directly as a normal HTML file will not execute the PHP.

File 3 — info.php
<?php
phpinfo();
?>

Explanation: phpinfo() displays information about the installed PHP configuration. Open http://localhost/web_lab/info.php.

Expected Result: HTML pages open in the browser and PHP output is generated by Apache/PHP.

Practical 2: Create a Web Page Using Semantic HTML5

Aim: Create a basic web page using semantic HTML5 tags, headings, lists, tables, hyperlinks and multimedia elements.

HTML5 Explanation

HTML (HyperText Markup Language) provides the structure of a webpage. Semantic HTML5 elements describe the meaning of the content, making pages more understandable and accessible.

TagPurpose
<header>Introductory/header content.
<nav>Navigation links.
<main>Main content of the page.
<section>Thematic section of content.
<article>Independent content.
<aside>Related/secondary content.
<footer>Footer information.

Practical 3: Design Web Pages Using CSS

Aim: Style webpages using CSS selectors, colors, backgrounds, borders, margins, padding and positioning.

What is CSS?

CSS (Cascading Style Sheets) controls the presentation of HTML elements. It can control colors, fonts, spacing, borders, dimensions and positioning.

File 1 — css-demo.html
<!DOCTYPE html>
<html lang="en">
<head>
    <title>CSS Demonstration</title>
    <link rel="stylesheet" href="style.css">
</head>

<body>

    <div class="container">

        <h1>CSS Styling Example</h1>

        <p id="intro">
            CSS is used to control the appearance of HTML elements.
        </p>

        <div class="box">
            This box demonstrates the CSS Box Model.
        </div>

        <button>Learn More</button>

    </div>

</body>
</html>
File 2 — style.css
/* Element selector */
body {
    background-color: #f1f5f9;
    font-family: Arial, sans-serif;
}

/* Class selector */
.container {
    width: 70%;
    margin: 50px auto;
    padding: 30px;
    background-color: white;
    border: 2px solid #334155;
}

/* ID selector */
#intro {
    color: #2563eb;
    font-size: 18px;
}

/* Class selector */
.box {
    background-color: #dbeafe;
    border: 3px solid #2563eb;
    margin: 20px;
    padding: 25px;
    position: relative;
    left: 10px;
}

/* Element selector */
button {
    padding: 10px 20px;
    color: white;
    background-color: #1d4ed8;
    border: none;
    border-radius: 5px;
}

CSS Selectors

SelectorExampleMeaning
Elementp { }Selects all paragraph elements.
Class.box { }Selects elements having class="box".
ID#intro { }Selects the element having id="intro".
Universal* { }Selects all elements.

CSS Box Model

The CSS Box Model consists of content → padding → border → margin. Padding creates space inside the border, while margin creates space outside it.

Positioning Example

position.html
<style>
.container {
    position: relative;
    height: 200px;
    border: 2px solid black;
}

.box {
    position: absolute;
    right: 20px;
    bottom: 20px;
    padding: 15px;
    background-color: orange;
}
</style>

<div class="container">
    <div class="box">Positioned Element</div>
</div>
Result: Web pages were successfully styled using CSS selectors, colors, backgrounds, borders, margins, padding and positioning.

Practical 4: Responsive Layout Using Flexbox and CSS Grid

Aim: Design responsive web page layouts using CSS Flexbox and CSS Grid Layout.

Flexbox

Flexbox is mainly used for arranging elements along one dimension: a row or a column. Common properties include display: flex, justify-content, align-items and flex-wrap.

File 1 — flexbox.html
<!DOCTYPE html>
<html>
<head>
<title>Flexbox Example</title>

<style>
.container {
    display: flex;
    justify-content: space-between;
    align-items: center;
    gap: 20px;
    flex-wrap: wrap;
}

.item {
    flex: 1;
    min-width: 200px;
    padding: 30px;
    background-color: lightblue;
    text-align: center;
}
</style>
</head>

<body>

<h1>Flexbox Layout</h1>

<div class="container">
    <div class="item">HTML</div>
    <div class="item">CSS</div>
    <div class="item">JavaScript</div>
</div>

</body>
</html>

CSS Grid

CSS Grid is a two-dimensional layout system. It is useful for creating rows and columns. grid-template-columns defines the columns and gap controls spacing.

File 2 — grid.html
<!DOCTYPE html>
<html>
<head>
<title>CSS Grid Example</title>

<style>
.container {
    display: grid;
    grid-template-columns: repeat(3, 1fr);
    gap: 20px;
}

.item {
    padding: 30px;
    background-color: lightgreen;
    text-align: center;
}

@media (max-width: 768px) {
    .container {
        grid-template-columns: 1fr;
    }
}
</style>
</head>

<body>

<h1>CSS Grid Layout</h1>

<div class="container">
    <div class="item">HTML</div>
    <div class="item">CSS</div>
    <div class="item">JavaScript</div>
    <div class="item">PHP</div>
    <div class="item">MySQL</div>
    <div class="item">Bootstrap</div>
</div>

</body>
</html>

Responsive Media Query

responsive.css
/* Desktop: 3 columns */
.container {
    display: grid;
    grid-template-columns: repeat(3, 1fr);
}

/* Tablet/mobile: 1 column */
@media (max-width: 768px) {
    .container {
        grid-template-columns: 1fr;
    }
}

The media query changes the layout when the screen width becomes 768 pixels or less. This is one of the basic techniques used in responsive web design.

Result: Responsive layouts were successfully created using Flexbox, CSS Grid and media queries.

Responsive Bootstrap Grid

Bootstrap uses a 12-column grid. For example, col-md-6 means the element occupies 6 of 12 columns on medium and larger screens. On smaller screens, Bootstrap columns normally stack unless another breakpoint class is specified.

Mini Project: Student Registration Portal

Objective: Combine HTML5, CSS3, responsive design and Bootstrap into a small practical project.

Create a folder named student-portal and save the following files inside it. This demonstrates how multiple files work together.

Folder Structure

Mini Project — register.php
<?php

$name = htmlspecialchars($_POST["name"] ?? "");
$email = htmlspecialchars($_POST["email"] ?? "");
$course = htmlspecialchars($_POST["course"] ?? "");

echo "<!DOCTYPE html>";
echo "<html><head><title>Registration Result</title></head><body>";

echo "<h1>Registration Successful</h1>";
echo "<p>Name: $name</p>";
echo "<p>Email: $email</p>";
echo "<p>Course: $course</p>";

echo "</body></html>";

?>

How the Mini Project Works

  1. The user opens index.html.
  2. The Bootstrap grid creates a responsive layout.
  3. The user fills in the registration form.
  4. The form sends data to register.php using the POST method.
  5. PHP reads the submitted values and displays them.
Important: The mini project must be placed inside XAMPP's htdocs directory and accessed through Apache, for example: http://localhost/student-portal/. PHP will not execute if index.html or register.php is opened directly from the file system.
